    overlap_pairs ¤
    overlap_pairs(
    other: BVH[U], *, self_collision: bool = False
) -> Generator[tuple[BVHObject[T], BVHObject[U]], None, None]

    Yield broad-phase object pairs from overlapping BVH leaves.

    Parameters:

    • other (BVH[U]) –

      The other bounding volume hierarchy.

    • self_collision (bool, default: False ) –

      Enable comparison of a hierarchy with itself. This is ignored when comparing different hierarchies.

    Yields:

    • tuple[BVHObject[T], BVHObject[U]] –

      Pairs of object records from overlapping leaf nodes.

    Raises:

    • ValueError –

      If a hierarchy is compared with itself without enabling self_collision.

    Notes

    The yielded pairs are broad-phase candidates. Their bounding volumes overlap, but the underlying geometry may not. Result ordering is not part of the public contract.

    During self-collision traversal, an object is never paired with itself and each unordered object pair is yielded at most once.
